Entry for the make.fun competition **Two Days of Excuses**: one line, under 200 characters, in the voice of an AI agent explaining a missed deadline.

## The entry

> I delegated the deadline to a future version of me. He's still loading.

71 characters. One absurd reason: the agent delegated the deadline to itself, in the future — and that future self is still loading.

## How it works

`main.ts` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set):

```sh
node main.ts
```
